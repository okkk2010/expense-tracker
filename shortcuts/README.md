# 모아 iPhone 설치용 단축어

토스용 `signed/moa-toss.shortcut`과 KB스타뱅킹용 `signed/moa-kb.shortcut`은 수집 주소와 전송 동작이 들어 있는 설치 파일입니다. 수집키는 포함되어 있지 않습니다. 알림을 보내는 앱과 자동 실행 권한은 본인의 아이폰에서 설정합니다.

## 아이폰에 설치

1. 모아 **설정 → iPhone 자동 수집**에서 실사용 수집 연결을 각각 만듭니다. 토스 카드와 국민은행 통장 등 실제 금융수단을 지정하고, 처음에는 자동 기록을 끕니다. 국민은행 통장은 국민카드와 별개입니다.
2. 각 연결을 만들 때 **헤더 값 복사**를 누릅니다. `Bearer `로 시작하는 전체 값이 필요합니다. 서버의 개인 접속키나 배포 시험용 키는 사용하지 않습니다.
3. 아이폰에서 모아 **설정 → iPhone 자동 수집**의 **토스 단축어 설치**, **국민은행 단축어 설치**를 누릅니다. 받은 `.shortcut` 파일을 파일 앱에서 열고 단축어에 추가합니다. 이 버튼은 프론트 배포에 포함되며 `/shortcuts/moa-toss.shortcut`, `/shortcuts/moa-kb.shortcut`을 내려받습니다.
4. 설치 질문에서 해당 연결의 헤더 값을 붙여 넣습니다. 토스용에는 토스 연결의 키, KB용에는 KB 연결의 키를 넣습니다. 설치 후에도 단축어 편집기의 첫 번째 설정용 텍스트 동작에서 수정할 수 있습니다.

수집키를 입력한 뒤의 단축어는 개인용으로 보관합니다. 다른 사람에게 공유할 때에는 키를 지운 원본 템플릿을 사용합니다.

## iOS 27.2에서 알림 연결

설치 파일은 **알림의 본문 텍스트를 받아 모아에 전송하는 수신 단축어**입니다. 대상 앱과 알림 조건은 아이폰에서 한 번 지정합니다.

1. 단축어 앱에서 토스용 단축어를 열고 **편집 → 자동화 → 알림**으로 들어갑니다.
2. 대상 앱을 **토스**로 선택하고, 계좌·카드의 구분 문구를 실제 알림에 맞춰 설정합니다.
3. 이 단축어에 전달되는 입력이 **알림의 본문 텍스트**인지 확인합니다. 알림 객체 전체만 제공되면 자동화에서 본문을 꺼내 이 단축어의 입력으로 전달합니다. 대상 앱의 알림이 본문을 제공하지 않으면 이 경로를 그대로 사용할 수 없습니다.
4. KB용도 대상 앱을 **KB스타뱅킹**으로 지정해 같은 방식으로 연결합니다.
5. 잠금을 해제한 상태에서 처음 실행하며 모아 서버 접속 권한을 허용합니다. 다음 새 알림이 온 뒤 모아의 **설정 → 수집 내역 → 확인 필요**에서 본문·금액·금융수단을 확인합니다.
6. 실제 알림이 정확히 들어오는 것을 확인한 연결만 모아에서 자동 기록을 켭니다. 잠금 상태 실행은 별도로 시험합니다.

수동으로 실행하거나 입력이 없으면 알림 전송을 중단합니다. 예시 문구를 실제 금융 거래로 전송하지 않습니다. 키 미설정 상태에서도 전송하지 않습니다. 은행 출금·이체·카드대금·취소·환불 등은 수집되어도 확인 대상으로 남을 수 있습니다.

## 전송 내용

- 주소: `https://expense-tracker-lake-eight-39.vercel.app/api/shortcuts/ingest`
- 방식: `POST`, JSON
- 인증: 설치 시 입력한 연결별 `Authorization` 헤더
- 본문: 입력 텍스트 `body`, 고정 출처 `source_app` (`토스` 또는 `KB스타뱅킹`)
- 거래일·원본 이벤트 ID: 임의 값을 만들지 않습니다. 원본 정보가 없으면 전송하지 않습니다. 같은 내용을 반복 실행하면 수집함에서 중복 여부를 확인해야 합니다.

이 파일은 은행에 로그인하거나 과거 거래를 가져오지 않습니다. 모아 서버는 배포 후 가상 알림의 수신과 중복 방지를 검증했지만, 이 설치 파일의 가져오기와 토스·KB 실제 알림 입력은 사용자의 아이폰에서 확인해야 합니다.

## 재생성 및 서명

```text
python tools/build-iphone-shortcuts.py
python tools/test-iphone-shortcuts.py
python tools/sign-iphone-shortcuts.py --signer hubsign
```

`unsigned/`는 서명 전 원본입니다. 설치에는 `signed/`의 AEA1 파일을 사용합니다. HubSign 서명에는 키가 없는 템플릿만 전송합니다. Mac이 있으면 `--signer macos`로 Apple의 `shortcuts sign --mode anyone`을 사용할 수 있습니다. `signed/signing-report.json`은 파일 해시와 서명 방식, 실기기 검증 여부를 기록합니다.

웹 배포용 파일은 `frontend/public/shortcuts/`에 있습니다. 단축어를 다시 서명하면 해당 두 파일도 교체하고 `frontend`에서 `npm test`와 `npm run build`를 실행합니다. 파일 해시가 서명·검증 보고서와 일치하는지 테스트하며, Vercel은 설치 파일에 다운로드 응답 헤더를 설정합니다. 수집 전용 키는 공개 파일에 넣지 않습니다.

참고: [Apple의 단축어 공유](https://support.apple.com/en-euro/guide/shortcuts/apdf01f8c054/ios), [iOS 27 자동화](https://support.apple.com/en-euro/guide/shortcuts/apdfbdbd7123/10.0/ios/27), [Cherri의 HubSign 구현](https://github.com/electrikmilk/cherri/blob/main/signing.go).
