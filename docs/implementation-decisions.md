# 초기 구현 선택과 후속 조정

사용자는 남은 네 가지 질문을 지금 더 결정하지 않고 개발을 진행하도록 요청했습니다. 다음은 사용자의 확정 답변과 구분한 변경 가능한 초기 구현입니다.

| 항목 | 초기 구현 |
| --- | --- |
| 첫 화면 지표 | 월 지출, 종목별 지출, 개별 태그 예산을 배치합니다. |
| 태그 중복 | 총지출은 거래 한 건을 한 번만 계산합니다. 태그별 수치는 겹칠 수 있음을 구분합니다. 예산은 태그별 계산을 확인할 수 있게 합니다. |
| 태그 삭제 | 과거 연결을 유지하는 보관과 과거 연결도 지우는 삭제를 구분해 선택하게 합니다. |
| 저장본 수정 후 저장 | 새 저장본 생성과 기존 저장본 갱신을 구분해 제공합니다. |

입력 주간 고정, 수입·잔액 강제 연결, 투자 기록, 오프라인 입력, 핀 버튼 등의 요구를 새로 추가하지 않습니다. 현재 투자 계획 없음·온라인 전제·핀 불필요는 사용자의 명시적인 답변에 따른 것입니다.

프론트와 백엔드 배포를 분리하므로 프론트 소스에는 DB나 모델 서비스 비밀키를 두지 않습니다. 개인 접속키는 계정 없이 본인 기기에서 서버를 연결하기 위한 구현 선택입니다. 서비스 공개 회원가입을 추가하지 않습니다.
